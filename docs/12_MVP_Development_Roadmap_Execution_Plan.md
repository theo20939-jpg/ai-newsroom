# 1. Назначение документа

Документ определяет порядок разработки MVP.

Используется как инструкция:

- для Claude Code;
- для разработчика;
- для контроля прогресса.

---

# 2. Цель MVP

Создать Telegram-бота, который:

1. Получает новости из источников.
2. Сохраняет их.
3. Анализирует через AI.
4. Оценивает важность.
5. Формирует подборки.
6. Создаёт черновики контента.
7. Отправляет результат SMM-команде.

---

# 5. Правила работы с Claude Code

---

## Правило 1

Один этап → одна проверка.

Не переходить дальше без теста.

---

## Правило 2

После каждого этапа:

Claude должен предоставить:

- список созданных файлов;
- что реализовано;
- как проверить;
- возможные ошибки.

---

## Правило 3

Не менять архитектуру без согласования.

---

## Правило 4

Любое новое решение:

сначала описать.

Потом реализовать.

# 6. Definition of Done MVP

Проект готов, когда:

---

✅ Бот работает в Telegram.

---

✅ Новости автоматически собираются.

---

✅ AI анализирует новости.

---

✅ Есть рейтинг новостей.

---

✅ Формируется ежедневная подборка.

---

✅ Создаются черновики постов.

---

✅ Команда может использовать бота ежедневно.
