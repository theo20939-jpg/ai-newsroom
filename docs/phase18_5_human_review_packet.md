## How to use this packet

For each item, record:

- **human_decision** — one of `good_meme_candidate` / `weak_candidate` / `not_a_meme` / `unsafe`
- **human_notes** — free text: why, what's missing, what would make it better/worse

This is the calibration input `docs/phase18_5_final_report.md` (M4) will use to assess whether
M1's opportunity-detection thresholds need recalibration, and to give the eventual GO/NO-GO
recommendation for enabling `meme_opportunity_mode="shadow"` in real production a human-reviewed,
not merely heuristic, foundation.
