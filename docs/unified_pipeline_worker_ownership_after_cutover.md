# Worker ownership: before vs. after the cutover

UNIFIED-EDITORIAL-PRODUCTION-PIPELINE-CUTOVER-1. Scope: `settings.unified_editorial_pipeline_enabled
== True` AND a real V8-family copywriting output (`is_unified_router_eligible()`) — the only shape
any real production send has ever produced. Every other case (flag off, or a non-V8 shape) is
served by the legacy path, byte-identical to before this phase.

"BEFORE" reflects the state documented in `artifacts/unified_editorial_pipeline_review_bundle_1/
06_WORKER_OWNERSHIP.md` (the prior phase's own honest finding: *"Nothing was moved... 41 lines
added, 0 removed... no responsibility has actually transferred yet"*). "AFTER" reflects this
phase's real code, not aspiration.

## Responsibility count — did the worker actually get thinner for the cases it now defers?

For the flag-on + V8-family case specifically (the only case this phase changes), `worker/content_cycle.py`'s own code for that case shrank from the ~900-line inline decision tree (lines 1454-2338, pre-cutover) to ~35 lines that: fetch two already-established signals, call one function, and translate four outcome fields into existing counters. The ~900-line legacy tree itself is untouched, byte-for-byte, inside the `else:` branch — it still exists (S3: "do not delete the legacy pipeline yet"), but it is **structurally unreachable** for any real V8-family send once the flag is on.

```
ORCHESTRATOR_IS_AUTHORITATIVE_WITH_FLAG_ON = true
```

Verdict basis: for the scope this phase actually cuts over (single-photo-or-text NEWS/BREAKING/DATA/QUOTE delivery), every one of format selection, DATA extraction, media selection, composition strategy, caption budget, quality gate, and recovery decision is made exactly once, inside the orchestrator/telegram_integration/RecoveryService — never re-decided or re-inspected by `worker/content_cycle.py` afterward. The one disclosed exception (media groups/video) is out of scope by an explicit, reasoned decision (current production default for those features is off/shadow), not an oversight.
