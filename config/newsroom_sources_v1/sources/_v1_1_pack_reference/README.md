## Интеграция
1. Не заменять v1. Скопировать `sources/*.yaml` рядом с существующими source-configs либо в каталог,
   который уже сканирует текущий конфиг-лоадер.
2. Не менять Workflow, БД, очереди, Analyzer/Scorer/Deduplicator.
3. Использовать существующие адаптеры по `type`/`adapter`.
4. Источники с `requires_adapter` и `auth` включать только при наличии credentials.
5. Перед merge запустить проверку уникальности `id`, URL и имени между v1 и v1.1.
6. Источник с ошибкой не должен останавливать общий цикл Collector.

## Важное замечание
Инсайдеры являются сигналом раннего обнаружения, а не подтверждением факта.
Материал от инсайдера должен получить статус `unverified` до подтверждения официальным источником
или несколькими независимыми надежными источниками.
